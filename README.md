Projektbeskrivning:

MovieFlix är en streamingplattform med filmer och tv-serier. 
Uppe i naven finns sökfunktionalitet. 
Du kan även via länk via footern publicera en egen film via ett formulär. 
På sidan My List finns det funktionalitet för rating. 
På sidan TV-serier kan du filtrera mellan olika genrer. 

Medlemmar i gruppen:
Hussein, Elina, Admir och Matilda
